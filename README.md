# Network Packet Sniffer

## Description
This project is a Network Packet Sniffer developed using Python and Scapy. It captures network packets and displays important information such as Source IP Address, Destination IP Address, Protocol, and Payload.

## Features
- Captures network packets
- Displays Source IP Address
- Displays Destination IP Address
- Displays Protocol Number
- Displays Packet Payload
- Shows Packet Number and Time

## Requirements
- Python 3.x
- Scapy
- Npcap (Windows)

## How to Run
1. Install Python.
2. Install Scapy using:
   pip install scapy
3. Install Npcap.
4. Run the program:
   python network_sniffer.py
